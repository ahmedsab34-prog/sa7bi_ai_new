# Sa7bi AI - صحبي AI

تطبيق ذكي متعدد الخدمات (Arabic AI Super App) مصمم خصيصاً بواجهة عصرية فخمة (Glassmorphism & 3D Luxury Design) ودعم كامل للغة العربية.

## مميزات التطبيق:
* واجهة مستخدم فخمة تتضمن الشعار المميز (`@i`) واسم التطبيق بتأثيرات ذهبية.
* شريط تنقل سفلي مرن يربط بين الرئيسية، الأقسام العشرة، والصفحة الشخصية.
* دعم الأقسام العشرة المتنوعة (المطبخ، التاجر، الصيدلية، الصنايعي، العبادات، الشراء، التواصل، الفضفضة، الرياضة، والبودكاست).
* تكامل رسمي مع نموذج Google Gemini AI للدردشة والمساعدة الذكية.
* نظام إعدادات مرن لإدخال وحفظ مفتاح التشغيل بأمان.

## معلومات المستودع:
* **المنصة:** Flutter / Android
* **المطور:** أحمد سليمان (ahmedsab34-prog)
